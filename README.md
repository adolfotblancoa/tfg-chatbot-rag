# tfg-chatbot-rag
Trabajo de Fin de Grado centrado en el diseño, implementación y evaluación de un asistente conversacional institucional basado en arquitectura RAG.

## Stack inicial

- FastAPI
- ChromaDB
- SQLite
- OpenAI API
- Nginx

## Objetivo

Construir un backend capaz de responder consultas institucionales usando recuperación semántica y generación con modelos de lenguaje.
